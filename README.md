## ¿Qué es KYO?
KYO nació porque necesitaba una forma bonita y sencilla de organizar mis estudios.
Es una web que empieza vacía y se va llenando con tus tareas, tus notas y tus sesiones de estudio.

## Funciones
- ✅ **Pendientes**: añade tareas y márcalas como hechas
- ⏱️ **Pomodoro**: temporizador para estudiar por bloques
- 📊 **Notas y rendimiento**: registra tus notas y mira cómo vas
- 📱 **Responsive**: funciona en el ordenador y en el móvil

## Tecnologías
HTML · CSS · JavaScript (sin frameworks)
